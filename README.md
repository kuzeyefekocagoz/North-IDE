# [**</> North IDE**](https://kuzeyefekocagoz.github.io/North-IDE/)

Tarayıcı üzerinde Python kodu yazıp çalıştırabileceğiniz hafif ve modern bir web IDE.

## Özellikler

* Python kod çalıştırma
* Monaco Editor
* Otomatik tamamlama
* Hata analizi
* Çıktı konsolu
* Dosya oluşturma ve silme
* `.py` dosyası olarak kaydetme
* Mobil ve masaüstü desteği
* Responsive arayüz

## Teknolojiler

* HTML
* CSS
* JavaScript
* Monaco Editor
* Pyodide

## Kullanım

`index.html` dosyasını modern bir tarayıcıda açmanız yeterlidir.

Python kodları Pyodide sayesinde tarayıcı içerisinde çalışır.
